
# 11A. Hapus Elemen List

| Time Limit | Memory Limit |
|------------|--------------|
| 2 s        | 256 MB       |

## Deskripsi

Buat program fungsional Scala untuk menghapus semua elemen bilangan bulat yang sama dan bersebelahan.

## Constraints

- **Style:** Pemrograman fungsional.
- **Dilarang:** `var`, `while`, `for` imperatif, dan mutasi data kecuali pada proses membaca input data.
- **Wajib:** Fungsi murni (*pure function*), Higher-Order Function (HOF), struktur data dan container, serta fungsi rekursif.

## Format Input

Input data diberikan dengan format:

```text
A1 A2 … AN
```

## Format Output

Deretan bilangan bulat hasil penghapusan elemen yang sama dan bersebelahan.

## Sample Input

```text
1 1 1 4 3 4 1 1 1 1 1 7
```

## Sample Output

```text
4 3 4 7
```
